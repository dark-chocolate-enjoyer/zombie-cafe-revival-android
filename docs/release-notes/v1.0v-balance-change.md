This release is the first full balance-focused version of Zombie Cafe Revival.

The main goal is to make the game feel fresher, less grindy, and more rewarding while keeping the original Zombie Cafe feel.

## Main changes

- Rebalanced food prices, servings, and profits so more recipes are worth cooking.
- Reworked XP so progression stays closer to vanilla XP-per-minute pacing instead of becoming too fast.
- DLC and premium cookbook recipes are now intentionally stronger and more worthwhile.
- Special stove-chain recipes now feel more like actual upgrades.
- Playable chefs were rebalanced so late-game chefs have stronger identities.
- Infectable zombies/staff were rebalanced: Maids are still useful safe workers, Governor is now the top tip specialist, Godfather is the best all-rounder, and Zombie Man is an elite combat monster.
- Cash-to-toxin exchange prices were raised to match the stronger food economy.
- Includes the existing Android/BlueStacks compatibility fixes.
