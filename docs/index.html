Scope

Project changes

The work is divided between runtime maintenance and data balancing, with investigation notes retained alongside the source.

  • Music playback

    Repairs stale native playback state, restores cafe rotation and raid themes, keeps the map silent, and recovers ten OGG assets from the later Japanese build. Implementation details

  • Character balance

    Reworks playable chefs and infectable staff across cost, energy, regeneration, combat, speed, and tip value so more of the roster remains useful.

  • Food economy

    Retains the v1.0 progression pass for recipe timing, earnings, experience, premium dishes, and special-stove chains.

  • Japanese build

    Ongoing work covers English localization, Android compatibility, balance transfer, and a local cash-to-Toxin exchange that replaces the retired server purchase path. Implementation details

Runtime

Installation and limitations

This remains a legacy 32-bit Android game and carries some constraints from the original application.

  • The APK requires a device or emulator with 32-bit ARM application support.
  • Installation is by sideloading; the package is not distributed through Google Play.
  • The English build has been exercised in BlueStacks. Hardware and newer Android versions may behave differently.
  • Some original instability may remain around map and raid transitions. The music repair does not claim to resolve every legacy crash.
  • The Japanese translation and compatibility build is a separate workstream and is not part of the v1.1.0 English APK above.
